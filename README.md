**NetScope** is a production-grade network discovery, continuous monitoring, and automated security posture platform comparable to Fing, Domotz, and RunZero.

## API Endpoints

- **Health Check:** `/health`
- **Interactive API Docs:** `/docs`
- **Devices:** `/api/v1/devices`
- **Networks:** `/api/v1/networks`
- **Alerts:** `/api/v1/alerts`
- **Content Filtering:** `/api/v1/filtering`
